## Reporting a Vulnerability

The StaffSync engineering team takes security and data privacy seriously. If you discover a security vulnerability in this project:

1. **Do not disclose the issue publicly** in GitHub issues or public forums.
2. Please report the issue privately to **Vansh Singh Yadav** via email at `vanshsinghyadav18@gmail.com`.
3. Please include:
   - A detailed description of the vulnerability.
   - Steps to reproduce or proof-of-concept payload.
   - Any proposed remediations.

We will acknowledge receipt within 48 hours and work on deploying a patch swiftly.
